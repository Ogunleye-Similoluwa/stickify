# Security policy

If you find a security problem, such as a way to make the server fetch arbitrary URLs, read files, or run commands, **please don't open a public issue**.

Instead, report it privately using GitHub's **Report a vulnerability** button on the repository's **Security** tab. Include the steps to reproduce it and what you think the impact is.

You'll get a reply as soon as possible, and a fix will be released before the issue is made public.
